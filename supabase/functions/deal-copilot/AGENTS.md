# deal-copilot
- Durable jobs and atomic human decisions enforce membership, term-edit rights and stale values — AI never approves.
- The coordinator delegates to four specialists (compliance, pricing, ESG, communications) via specialists.ts; panels run on save/upload and persist in report JSON v2 — drafts never sent, communications XML stays an unvalidated draft.
- Co-Pilot is the intended primary due-diligence surface: Deal Checker resources come only through knowledge/tools.ts (live checker results sent by the browser via src/lib/copilot/liveChecks.ts, GLEIF/OpenFIGI, holiday tables mirroring src/lib/bondValidator.ts, knowledge/library.ts generated by scripts/gen-copilot-library.mjs from reference/ and schema/) — regenerate the library and keep calendars in step when those sources change.
