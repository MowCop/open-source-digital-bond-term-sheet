# Demo deal: Meridian Gulf Bank Tier 2 US$ Reg S 10.5NC5.5 Social Sukuk

**Fictional.** Meridian Gulf Bank, Meridian Gulf Sukuk Limited, the banks, LEIs, ISIN, ratings and every number here are invented to demonstrate the Digital Deal Room. Nothing in this folder describes a real transaction or is an offer of securities.

The four syndicate messages are numbered in the order they are replayed:

| # | File | Stage | Key terms |
|---|------|-------|-----------|
| 1.1 | `1.1_IPTs.txt` | Initial price thoughts | IPTs T+205bps area, US$ Benchmark, 10.5NC5.5, pricing 3 Sep 2026, issue 10 Sep 2026, dissolution 10 Mar 2037, reset 10 Mar 2032 |
| 2.0 | `2.0_Books.txt` | Books | Books over US$1.4bn (ex JLM interest) |
| 3.0 | `3.0_Launched.txt` | Launch | US$500mn (no grow), spread set at T+175bps |
| 4.0 | `4.0_Priced.txt` | Priced | US$500,000,000, T+175bps, reoffer 100, profit rate 5.807%, ISIN XS9990000028, Common Code 999000002 |

Each message also has an `.html` version, which the New Issue Board shows. The plain text is what the parser reads during replay.

Attachments sent with message 1.1 are placeholder PDFs in `public/deal-docs/meridian-gulf-*.pdf`.

The demo script (deal seed, illustrative chat and stage snapshots) is in `src/data/demoDeal.ts`.
